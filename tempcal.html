Thermocouple / RTD Calibrator

Simulate and measure temperature sensors for accurate process control and calibration.

Essential Calibration

🔍 What is a Temperature Calibrator?

A temperature calibrator is a specialized tool used to test and calibrate temperature sensors and transmitters. It can simulate (source) temperature signals and measure real temperature from sensors.

  • 📤 Simulate: Generate thermocouple (mV) and RTD (ohms) signals
  • 📥 Measure: Read temperature from thermocouples and RTDs
  • 📊 Calibrate: Verify and adjust temperature transmitters
  • 🔧 Troubleshoot: Isolate problems in temperature loops

📋 How to Calibrate a Temperature Transmitter

  1. Isolate the transmitter from the sensor
  2. Connect the calibrator to the transmitter input
  3. Connect a loop calibrator to measure mA output
  4. Simulate zero value (e.g., 0°C) and note mA (should be 4mA)
  5. Simulate span value (e.g., 100°C) and note mA (should be 20mA)
  6. Check intermediate points: 25%, 50%, 75%
  7. Adjust if needed using zero and span adjustments
✅ Best Practice: Always match the thermocouple type (J, K, T, etc.) exactly. Using the wrong type introduces errors.
